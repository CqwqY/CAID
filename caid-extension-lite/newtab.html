插件生态
用 JavaScript 自制侧边栏区块，零部署。代码运行在轻量沙箱中，只暴露受控 API（storage / el / fetch / toast / 定时器），安全可控。详见下方「插件开发指南」。
插件开发指南

一个插件就是调用一次 CAID.plugin(def)。def 字段：

  • id：唯一标识（英文，如 my-clock）
  • name：侧边栏显示的名称
  • icon：lucide 图标名（如 clock / notebook），留空用 puzzle
  • mount(api)：渲染函数，注入时调用一次

mount 收到的 api：

  • api.container：你的内容容器（DOM 节点），往里塞东西
  • api.el(tag, props?)：创建 DOM 节点，props 支持 className/text/html/onClick 等
  • api.storage.get(key) / api.storage.set(key, val)：按插件 id 隔离的本地存储（异步，返回 Promise）
  • api.fetch(url, opt?)：发起网络请求（继承扩展跨域权限）
  • api.toast(msg)：弹出提示
  • api.setInterval(fn, ms) / api.setTimeout(fn, ms)：会被自动清理的定时器
  • api.onUnmount(fn)：插件被停用/删除时执行的清理

最小模板：

CAID.plugin({
  id: 'my-clock',
  name: '我的时钟',
  icon: 'clock',
  mount(api) {
    const box = api.el('div', { className: 'plugin-row' });
    api.container.appendChild(box);
    const tick = () => { box.textContent = new Date().toLocaleTimeString('zh-CN'); };
    tick();
    api.setInterval(tick, 1000);
  }
});

点击「插入模板」可把上面的代码填进编辑器，改改就能用。更多示例见仓库 PLUGINS.md。

设为首页 / 新标签页

浏览器出于安全限制，扩展无法自动修改「主页」设置。你可以手动将主页 / 启动时页指向本工作台：

本工作台地址
（CAID 扩展已接管新标签页，开新标签即为本工作台）
如何设置
  1. 打开浏览器 设置（地址栏输入 chrome://settings）
  2. 外观 → 开启「显示主页按钮」，并把主页设为上面的地址
  3. 启动时 → 选择「打开特定网页或一组网页」，添加上面的地址
  4. 若已安装 CAID 扩展：新标签页默认被接管为本工作台（常驻开启，可在扩展管理页停用/卸载本扩展以恢复浏览器默认新标签页）
