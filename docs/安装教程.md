# CAID 安装教程

> 本文档用于在本地安装并使用 CAID 纯净版扩展（不占用浏览器新标签页）。

## 一、系统要求

- 浏览器：基于 Chromium 内核（推荐 Microsoft Edge 或 Google Chrome）
- 操作系统：Windows / macOS / Linux
- 无需命令行操作，全程可在浏览器图形界面完成

## 二、下载扩展包

1. 打开扩展下载页（链接待填：【在此粘贴下载地址】）。
2. 下载最新版本的压缩包 `CAID-lite0.3.19.zip`。
3. 将压缩包解压到一个你不会删除的文件夹（例如 `D:\CAID` 或桌面），**解压后请记住该文件夹路径**，后续加载扩展会用到。

> 源仓库：GitHub 【待填：GitHub 仓库地址】

![下载页面截图——待补充](【待填：图片路径】)

## 三、加载扩展

1. 打开浏览器的扩展管理页面：
   - Edge：地址栏输入 `edge://extensions`；
   - Chrome：地址栏输入 `chrome://extensions`。
2. 打开页面右上角的 **「开发人员模式」** 开关。
3. 点击左上角 **「加载已解压的扩展程序」**。
4. 选择第二步解压得到的那个文件夹（即包含 `manifest.json` 的目录）。
5. 此时浏览器工具栏应出现 CAID 的图标，说明扩展已加载成功。

![扩展管理页面——待补充](【待填：图片路径】)
![点「加载已解压的扩展程序」——待补充](【待填：图片路径】)

## 四、配置 AI（LLM）

1. **右键点击**浏览器工具栏上的 CAID 图标 → 选择 **「选项」**，打开设置页。
2. 切到 **【副驾】** 页签。
3. 填写你的 **LLM（大模型）接口地址** 和 **API Key**：
   - 地址：待填写【在此粘贴 LLM 地址】
   - API Key：待填写【在此粘贴 API Key】
4. 也可暂时留空走内置免费代理，先体验功能，之后再填。
5. 保存设置。

![设置页——待补充](【待填：图片路径】)

## 五、开始使用

1. 打开任意网页。
2. **单击**右下角的 CAID 圆球，唤出副驾输入条；或**双击**展开完整面板。
3. 输入任务并回车，例如「搜索今天的天气」「打开 xxx 网站」。
4. 副驾会自动规划并逐步执行多步任务。
5. 发现副驾出错时，可在悬浮菜单点 **「纠错」**，错误会被记入 AI 错题本，此后副驾会遵守。

![圆球唤出副驾——待补充](【待填：图片路径】)
![副驾执行任务——待补充](【待填：图片路径】)

## 六、常用快捷键

| 操作             | 快捷键    |
| ---------------- | --------- |
| 启动副驾         | Ctrl + I + L |
| 一键终止任务     | Ctrl + L |
| 强行终止（备用） | 点圆球运行时左侧的「⏹」停止键 |

## 七、常见问题

- **加载后没看到 CAID 图标？** 可能是解压目录选错，请确认选中的是包含 `manifest.json` 的那一层。
- **副驾没有反应？** 请在【副驾】设置里核对 LLM 地址拼写正确且域名可达。
- **想恢复浏览器默认新标签页？** 纯净版不会接管新标签页，无需任何操作。
