设置
AI 回答 · LLM 配置
用于搜索框的 AI 回答模式。支持 DashScope（通义千问）、OpenAI、或自定义 API。此配置与 Page-Agent 完全独立。
降级策略
当未配置 Key 或 Key 失效时，使用规则引擎 + Demo LLM。您的 Key 仅保存在本地浏览器 localStorage。
Page-Agent · 运行模式
Page-Agent 是阿里巴巴开源的纯前端 GUI 智能体，用自然语言操控本页面 DOM（点击、输入、导航等）。当前使用 Demo 免费 LLM，仅供评估。
Demo 模式无需任何配置，页面右下角已自动出现 Page-Agent 面板。
Page-Agent · 自定义 LLM
切换到自定义模式后，Page-Agent 将使用此处的 LLM 配置，与 AI 回答的配置完全独立。适用于需要稳定服务的场景。
使用说明
  • 页面右下角的浮动面板即为 Page-Agent
  • 在面板中输入自然语言，如"清空搜索框""切换到 AI 回答模式""打开 GitHub"
  • Demo 免费 LLM 有配额限制，不稳定，正式使用请切换到自定义模式
  • Page-Agent 操控的是页面 DOM，不会跳出本页面
导出所有数据
将 localStorage + IndexedDB 的所有数据打包为 JSON 文件下载，用于备份或迁移。
导入数据
从 JSON 文件恢复数据。将覆盖当前数据，请先导出备份。
危险操作
此操作不可恢复，请谨慎使用。
