网页上的跨页 AI 副驾
让浏览器替你 自动干活

CAID 是一款浏览器智能体扩展。在任意网页唤出副驾，它自动规划并逐步完成搜索、填表、导航、取数等任务；内置纠错错题本让 AI 越用越懂你，打开副驾自动检查更新。

下载 v0.3.19 查看源码 · GitHub ↗

兼容 Chromium（Edge / Chrome）· 魔改 Page-Agent · 副驾完全本地可配

FEATURES

为高频浏览器操作而生

从"记一件事"到"在多网站间自动完成一串操作"，CAID 把复杂的多步过程交给 AI 规划与执行。

跨页智能体副驾

基于魔改 Page-Agent。在任意网页单击圆球唤出副驾，输入一句话即可由 LLM 自动规划多步 plan 并逐步执行。

多步自动规划

搜索、打开链接、点击、输入、添加待办……含连接词或多动词的任务自动拆成 plan，带进度条与确认点，敏感操作先征得同意。

AI 纠错错题本

发现副驾出错了？一键「纠错」记入错题本。副驾此后始终遵守，避免在同一件事上重蹈覆辙，越用越懂你。

顺手的快捷键

Ctrl+I+L 快速启动副驾，Ctrl+L 一键终止任务；圆球运行时左侧还有实体停止键，随时把控制权拿回来。

内置更新检查

打开副驾或进入工作台自动检查新版本，发现新版在面板顶部提示并一键跳转 GitHub 更新，不再错过修复。

轻盈不打扰

纯净版不接管你的新标签页，保留浏览器原生体验；副驾仅在你需要时出现，注入的 UI 不会被 AI 误认为网站内容。

INSTALL

三步装好

使用浏览器"加载已解压的扩展程序"即可，无需上架商店也能本地使用。

下载压缩包

下载 v0.3.19 的 CAID-lite0.3.19.zip（在 Release 页获取，直链会过期），解压到本地文件夹。

加载扩展

打开 edge://extensions 或 chrome://extensions，开启「开发人员模式」，点击「加载已解压的扩展程序」，选择该目录。

配置 LLM

右键扩展图标 → 选项，在【副驾】页填入你的 LLM 地址与 API Key（可留空走免费代理）。回到任意网页单击圆球即可开始。

开用

输入任务 → 副驾自动规划执行。出错随时「纠错」，养成你的 AI 错题本。

UPDATES

保持最新

版本检查由独立后端提供，扩展打开副驾或工作台时自动探测，也可以手动点「检查更新」。

LIVE VERSION

当前建议版本

最新版本由 changelog-production.up.railway.app 推送。发现新版时，扩展会在副驾面板顶部提示并一键带你到 GitHub Release 页。

GUIDE

CAID 安装教程

01系统要求

  • 浏览器：基于 Chromium 内核（推荐 Microsoft Edge 或 Google Chrome）
  • 操作系统：Windows / macOS / Linux

02下载扩展包

  • 打开扩展下载页：https://github.com/CqwqY/CAID/releases/tag/v0.3.19
  • 下载最新压缩包 CAID-lite0.3.19.zip
  • 解压到不会删除的文件夹（如 D:\CAID），记住该路径，后续加载要用
源仓库：GitHub https://github.com/CqwqY/CAID

03加载扩展

  • 打开扩展管理页：edge://extensions（Edge）或 chrome://extensions（Chrome）
  • 开启右上角 「开发人员模式」
  • 点击左上角 「加载已解压的扩展程序」
  • 选择第 02 步解压得到、包含 manifest.json 的文件夹
  • 完成后浏览器工具栏出现 CAID 图标即加载成功

04配置 AI（LLM）

  • 右键工具栏 CAID 图标 → 「选项」，打开设置页
  • 切到 【副驾】 页签
  • 填写 LLM 接口地址，API Key
  • 也可先留空走内置免费代理体验，之后再填
  • 保存设置

05开始使用

  • 打开任意网页，单击右下角圆球唤出副驾输入条，或双击展开完整面板
  • 输入任务并回车，如「搜索今天的天气」
  • 副驾自动规划并逐步执行多步任务
  • 发现出错可在悬浮菜单点 「纠错」，错误记入 AI 错题本，此后副驾会遵守

06常用快捷键

操作快捷键
启动副驾Ctrl + I + L
一键终止任务Ctrl + L
强行终止（备用）点圆球运行时左侧「⏹」停止键

07常见问题

  • 加载后没看到图标？确认解压目录选的是包含 manifest.json 的那一层
  • 副驾没反应？在【副驾】设置核对 LLM 地址拼写正确且域名可达
  • 想恢复浏览器默认新标签页？纯净版不会接管新标签页，无需操作
